# Hackathons & build sprints

You cannot list **every** college hackathon in one repo — thousands run each year. What you *can* do is know **where calendars live**, which **flagship events** repeat, and which **gov / company** hackathons pay off for students.

> Verify dates, fees, and eligibility on the **official** event page. Scammers clone popular names — see [stay-safe.md](../resources/stay-safe.md).

## Hackathons vs open-source programs

| | Hackathons | GSoC / Outreachy / SoB |
| --- | --- | --- |
| Duration | Hours to 48h (sometimes weeks online) | Weeks to months |
| Pay | Prizes / swag / sometimes jobs | Stipends |
| Best for | Prototypes, teams, networking | Deep contribution to one codebase |

Many students do **both**: hackathons for energy and teams, OSS programs for career-defining commits.
