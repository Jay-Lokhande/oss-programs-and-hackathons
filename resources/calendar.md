# Program calendar

## Subscribe (approximate planning dates)

Download or subscribe to **`data/deadlines.ics`**:

- **Raw file:** [deadlines.ics](https://github.com/Jay-Lokhande/oss-programs-and-hackathons/raw/main/data/deadlines.ics)
- Google Calendar → **Add other calendars** → **From URL** → paste the raw link above
- Apple Calendar → **File → New Calendar Subscription**

## Machine-readable JSON

[data/deadlines.json](../data/deadlines.json) — same events for scripts and PR updates.

## Live status

[osprograms.dev](https://www.osprograms.dev/) computes **open / closed** from verified dates.

## Update this calendar

When an official blog post announces dates, open a PR updating `deadlines.json` and `deadlines.ics` together. See [MAINTAINERS.md](../MAINTAINERS.md).
