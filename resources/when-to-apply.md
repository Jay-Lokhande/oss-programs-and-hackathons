# When to apply (rough calendar)

Dates shift every year — use this as a **planning map**, then confirm on [osprograms.dev](https://www.osprograms.dev/) and each official site.

| Months | Often happening |
| --- | --- |
| **Jan** | Summer of Bitcoin prep; **ESoC** info event (late Jan) |
| **Feb** | **Summer of Bitcoin** applications; **ESoC** batch 1; **24 Pull Requests** prep |
| **Mar** | **GSoC** contributor applications; **GSSoC** registration (some years); **ESoC** batch 2 |
| **Apr** | **C4GT** (some cycles); **SSoC** registration opens (some seasons) |
| **May–Aug** | Coding periods (GSoC, SoB, Outreachy May cohort, SSoC, OSPP, etc.) |
| **Jun–Jul** | **MLH Fellowship** fall applications (typical); **LFX** / **kernel mentorship** apps (some years) |
| **Aug** | **Outreachy** initial apps (Dec–Mar cohort); **LFX** apps (some terms) |
| **Oct** | **Hacktoberfest** |
| **Dec** | **24 Pull Requests**; **Season of KDE** apps (often ~December) |

## Year-round

- **Outreachy** — two cohorts (May & Dec starts); watch initial app windows
- **Igalia Coding Experience** — rolling / periodic
- **NLnet** — rolling grant calls

Add corrections via PR when you have an official announcement link.
