# Scams, fake internships & fraudulent “programs”

Students hunting for GSoC, Outreachy, Summer of Bitcoin, GSSoC, or hackathons are common targets. **Real programs never charge you to apply** and never ask for crypto wallet seeds.

Short checklist: [stay-safe.md](stay-safe.md). Report new patterns via [CONTRIBUTING.md](../CONTRIBUTING.md) (issue: scam pattern, not personal vendettas).

---

## Golden rules

1. **Apply only on the official domain** linked from the program’s own site (bookmark it — do not trust Google Ads).
2. **Never pay** registration, “processing”, or “guaranteed selection” fees.
3. **Never share** OTP, Aadhaar, passport scans, bank/UPI PIN, or **crypto seed phrases**.
4. **Stipends come after acceptance** through official channels — not upfront “verification deposits”.
5. If it sounds like a job but came from a **random Telegram/WhatsApp** group, treat it as fraud until verified on an official site.

## Fake “open source program” scams

| Scam type | What they claim | Reality |
| --- | --- | --- |
| **Fake GSoC** | “Register on our portal for guaranteed GSoC 2027” | GSoC is **only** [summerofcode.withgoogle.com](https://summerofcode.withgoogle.com/) |
| **Fake Outreachy** | Paid form + “fast track” | **Only** [outreachy.org](https://www.outreachy.org/) |
| **Fake Summer of Bitcoin** | BTC “registration fee” or wallet connect | **Only** [summerofbitcoin.org](https://www.summerofbitcoin.org/) — stipend paid **to you**, not by you |
| **Fake GSSoC / SSoC** | Clone sites with similar logos | Use [gssoc.girlscript.tech](https://gssoc.girlscript.tech/), [socialsummerofcode.com](https://socialsummerofcode.com/) — SSoC: only **socialsummerofcode@gmail.com** |
| **Fake LFX / “Linux Foundation internship”** | Email from `@gmail.com` “HR” | Mentorships via [mentorship.lfx.linuxfoundation.org](https://mentorship.lfx.linuxfoundation.org/) |
| **“Ambassador” / “Campus coordinator” fee** | Pay to represent a famous program | Legitimate programs may have volunteers; they **do not** sell titles for cash |

**Verify:** URL in the address bar, HTTPS, and cross-link from the foundation’s main site (Google, LF, Conservancy, etc.).

## Fake internship & job scams (general)

| Red flag | Why it’s suspicious |
| --- | --- |
| **Pay for internship / kit / software** | Real employers pay **you**, not the reverse |
| **“Training + placement” ₹/X fee** | Often unrelated to GSoC-style OSS; high pressure sales |
| **Offer letter before any interview** | Especially with urgent “accept in 24h” |
| **Interview only on WhatsApp/Telegram** | No verifiable company domain email |
| **@gmail.com / @yahoo.com “recruiter”** for big brands | Check careers page on `company.com` |
| **Reshipping / “task” apps** | Money mule / fraud — not internships |
| **Copy-paste LinkedIn jobs** | Same post for 50 “companies”; broken grammar + high pay |

**Verify:** Company careers portal, LinkedIn company page (blue check), and email domain `@company.com`.

## Hackathon & capture-the-flag scams

- Event exists **only** as Instagram poster — no Devfolio / Devpost / MLH / Unstop / official college domain.
- Form asks for **parent bank details**, full Aadhaar, or copies of ID “for prizes”.
- “Winners must pay shipping/tax upfront.”
- Phishing “Devfolio login” pages — check URL is exactly `devfolio.co`.

---

## Phishing & impersonation

- **Fake mentors:** “I’m a GSoC mentor, send repo access / SSH key / cloud API key.” Real mentors work through **public** org channels after you apply officially.
- **Fake GitHub org invites:** Read org name carefully; typosquat (`summer-of-code-google` vs real org).
- **Wallet / Web3 “stipend”:** Connect wallet to receive payment — **drains wallet**. Real SoB uses official onboarding after selection, not random DMs.
- **PDF offer letters** with only mobile numbers — no corporate letterhead verifiable online.

---

## Social engineering patterns

- **Urgency:** “Last 3 slots — pay now.”
- **Secrecy:** “Don’t tell your college; exclusive deal.”
- **Flattery + mismatch:** “Selected from 1% talent” but zero technical screen.
- **Moved off-platform:** “Leave GitHub, work in this private repo only” before any verified program acceptance.

## What real programs **do not** do

- Charge application fees (GSoC, Outreachy, ESoC, LFX, SoB, OSPP official flows).
- Ask for crypto seeds or “refundable security deposit” in USDT.
- Promise “100% selection” through a third-party “consultant”.
- Send stipend **before** you sign official paperwork / accept on the real portal.
- Run primary communication only in a **private** Telegram with no link from official site.

---

## If you already paid or shared data

1. **Stop** further payments; block the account.
2. **Bank/UPI:** Call issuer fraud line immediately.
3. **Passwords:** Rotate if you reused any; enable 2FA on GitHub, Google, email.
4. **Documents:** If Aadhaar/PAN leaked, note on cybercrime report; watch for loan fraud alerts.
5. **Report:** Official program (they track impersonation), platform (Telegram/WhatsApp where possible), [cybercrime.gov.in](https://cybercrime.gov.in/).
6. **Warn others** — issue/PR to this repo with **pattern** description (no doxxing).
