# Outreachy application checklist

Use for **each cohort** — rules on [outreachy.org/applicants](https://www.outreachy.org/applicants/).

## Before initial applications open

- [ ] Read current **eligibility** page in full
- [ ] Note **initial application** deadline (UTC) in calendar
- [ ] Draft personal background essays early (do not rush the last day)

## Initial application period

- [ ] Submit **initial application** before deadline (even if project list is incomplete)
- [ ] Watch for project list updates after deadline — this is normal

## Contribution period

- [ ] Pick 1–2 projects you can realistically contribute to
- [ ] Make **small merged or reviewed contributions** (docs and tests count)
- [ ] Use each org’s preferred communication channel only

## Final application

- [ ] Submit **final application** before deadline
- [ ] Reference specific contributions with links
- [ ] Explain schedule conflicts (exams, work) honestly

## After results

- [ ] If accepted: read intern agreement and onboarding from Outreachy + org
- [ ] If not: ask for feedback politely; keep contributing for next round
