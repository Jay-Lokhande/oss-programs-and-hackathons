# All You Have To Do Is Believe

A community-maintained guide to **paid open-source internships and mentorship programs** — GSoC, Summer of Bitcoin, Outreachy, LFX, and more.

These programs pay stipends, pair you with mentors, and give real experience on projects used in production. Many students never hear about them until it is too late to apply. This repo exists so **anyone can discover deadlines, eligibility, and official links in one place**.

> **Disclaimer:** Dates and stipends change every year. Always confirm on the program’s official site before you apply. Open a PR if something here is wrong or outdated.

## How to use this repo

1. Skim the tables and pick 2–3 programs that match your background.
2. Read the program page here, then read the **official** student guide.
3. Start contributing to the org **before** applications open (issues, docs, small PRs).
4. Put deadlines in your calendar using [when-to-apply.md](resources/when-to-apply.md) as a map.
