# What this repo intentionally does not list

## Organizations

There are **180+ GSoC organizations** alone each year, plus hundreds on Outreachy/LFX. Listing each org here would go stale instantly.

**Use instead:** [organizations/README.md](../organizations/README.md), [gsocorganizations.dev](https://gsocorganizations.dev/), [osprograms.dev/orgs](https://www.osprograms.dev/orgs).

## Individual hackathons

Thousands of college events run per semester. We list **platforms** and **annual flagships** only.

**Use instead:** [Devfolio](https://devfolio.co/hackathons), [MLH schedule](https://www.mlh.com/seasons/2026/events), [Unstop](https://unstop.com/hackathons).
