# Maintainer checklist

Use this **once per year** (or when official sites announce dates). Update program pages + [README.md](README.md) tables if stipends change.

| When | Program / event | Official source |
| --- | --- | --- |

| **Mar** | GSoC contributor apps | [summerofcode.withgoogle.com](https://summerofcode.withgoogle.com/) |
| **Mar–Apr** | GSSoC, SSoC registration (varies) | GSSoC / SSoC sites |
| **Apr+** | C4GT (some cycles) | [codeforgovtech.in](https://www.codeforgovtech.in/) |

| **Dec** | 24 Pull Requests, Season of KDE | Respective sites |

Live aggregator: [osprograms.dev](https://www.osprograms.dev/)

## PR review tips

- Require a link to an **official** announcement for date/stipend changes
- Do not merge copied text from program websites
- Hackathons: prefer platform links over one-off college events
