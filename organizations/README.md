# Organizations (where to contribute)

This repo lists **programs**. Organizations are who you actually code with. You cannot enumerate every org — use these browsers:

| Browser | URL | Use for |
| --- | --- | --- |
| GSoC orgs (current year) | [summerofcode.withgoogle.com/.../organizations](https://summerofcode.withgoogle.com/programs/2026/organizations) | 180+ mentoring orgs |
| GSoC org history & stacks | [gsocorganizations.dev](https://gsocorganizations.dev/) | Filter by language/topic |
| OS Programs org finder | [osprograms.dev/orgs](https://www.osprograms.dev/orgs) | GSoC + Outreachy + LFX |
| LFX active mentorships | [mentorship.lfx.linuxfoundation.org](https://mentorship.lfx.linuxfoundation.org/) | CNCF, Kernel, Hyperledger, … |
| Outreachy project list | [outreachy.org](https://www.outreachy.org/) | Per-round projects |

## Example org families (apply via programs above)

| Area | Examples |
| --- | --- |
| Bitcoin | Core-adjacent tools, wallets, education — see Summer of Bitcoin project list |
| Linux / cloud | Kernel, Kubernetes, CNCF projects, systemd, GNOME, KDE |
| Web / apps | Django (Djangonaut Space), Mozilla, Wikimedia, Ruby, Python, JS foundations |
| Science / India | FOSSEE, eSim, Spoken Tutorial |
| Security | OpenSSF, OWASP (GSoC/LFX when listed) |
| Hardware / Asia | FOSSASIA projects |

Start contributing **before** you apply: [../resources/first-contribution.md](../resources/first-contribution.md).
