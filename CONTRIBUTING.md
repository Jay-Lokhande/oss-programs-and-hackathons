# Contributing

Thank you for helping students find these opportunities.

## What to add

- New programs (create `programs/<slug>.md` and a row in `README.md`)
- Updated application windows with a link to the **official** announcement
- Corrections to stipend/eligibility with a source link

## Pull request checklist

- [ ] Official URL included
- [ ] No copied proprietary text from program sites — summarize in your own words
- [ ] Dates labeled as approximate if not confirmed on official site

## Style

- Keep pages short: what it is, who qualifies, stipend (if paid), timeline, official link
- Use Markdown only; no build step required
