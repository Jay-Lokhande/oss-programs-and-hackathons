# Contributing

Thank you for helping students find programs and hackathons.

## Open-source programs

- Add `programs/<slug>.md` and a row in [programs/CATALOG.md](programs/CATALOG.md)
- Add an entry to [data/programs.json](data/programs.json) (`name`, `slug`, `type`, `paid`, `url`)

## Hackathons

- **Do** add global **platforms**, **annual flagships**, and **national** events (e.g. SIH)
- **Do not** add single college hackathons — link [Devfolio](https://devfolio.co/hackathons) or [MLH](https://www.mlh.com/seasons/2026/events) in the event description instead
- Platform list: [data/hackathon-platforms.json](data/hackathon-platforms.json)

## Pull request checklist

- [ ] Official URL included
- [ ] Summarize in your own words (no copying full program text)
- [ ] Approximate dates labeled as approximate with a source link

## Style

Short pages: what it is, who qualifies, pay/prizes, timeline, official link. Markdown only.
