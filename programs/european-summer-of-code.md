# European Summer of Code (ESoC)

**What it is:** A worldwide program (not limited to EU citizens) that matches **open-source newcomers** with mentoring organizations. Multiple cohorts per year with spring application batches.

**Who can apply:** Open worldwide; especially aimed at people **new to open source**.

**Duration:** ~3 months per project.

**Stipend:** Paid stipends available; amount **varies by project** (see official site each round).

**Typical timeline:**

- Info event + applicant guide — often **late January**
- **Batch 1 applications** — often February–March (deadlines usually 18:00 UTC)
- **Batch 2 applications** — often April
- Projects start **April/May** depending on batch

**Official:** [esoc.dev](https://www.esoc.dev/)

**Tip:** Beginner-friendly alternative or complement to GSoC — read the applicant guide from the January info event before choosing orgs.
