# Google Season of Docs

**What it is:** Program for **technical writers** to improve documentation for open-source projects, with project grants (when Google runs the program — check each year).

**Who can apply:** Technical writers and doc-focused contributors pairing with accepted open-source organizations.

**Funding:** Often **~$5,000–$15,000 USD per project** (varies by year and project size).

**Official:** [developers.google.com/season-of-docs](https://developers.google.com/season-of-docs)
