# Nexus Spring of Code (NSoC)

**What it is:** ~**45-day** open-source contribution program (often **April–May**) with mentors, GitHub tracking, and certificates — community-driven (Nirmaan / Nexus ecosystem).

**Who can apply:** Students and developers worldwide — verify each year on the official site.

**Stipend:** Typically **certificates / recognition**, not a cash stipend like GSoC.

**Official:** [nsoc.netlify.app](https://nsoc.netlify.app/) (confirm current URL each cycle; also watch Unstop)

**Tip:** Often runs alongside other Indian seasons (GSSoC prep).
