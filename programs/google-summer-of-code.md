# Google Summer of Code (GSoC)

**What it is:** A global program where you spend ~12+ weeks contributing to a free/open-source project under mentor guidance, with a stipend from Google.

**Who can apply:** **18+**, students and non-students — you should be new or a beginner **to the org you apply to** (read current GSoC rules).

**Duration:** Often **12–22 weeks** depending on project size (175h vs ~350h style projects in recent years).

**Typical timeline (annual, dates shift):**

- Organizations announced — early year
- Contributor applications & proposals — often **mid–late March**
- Coding period — summer through fall (varies by project)

**Stipend:** Often **~$1,500–$6,600** USD equivalent, location-based (PPP). See the official stipend table each year.

**How to win:** Pick 1–2 orgs you genuinely care about, contribute before proposing, and write a specific proposal tied to their issue tracker.

**Official:** [summerofcode.withgoogle.com](https://summerofcode.withgoogle.com/)
