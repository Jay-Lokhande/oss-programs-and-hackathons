# Kubernetes Release Shadow Program

**What it is:** Learn **Kubernetes release engineering** by shadowing release team members (not a general coding internship).

**Who can apply:** Contributors with Go/K8s interest — application per release cycle.

**Stipend:** Typically **unpaid** learning role; high signal for CNCF/LFX paths.

**Official:** [k8s.dev](https://www.k8s.dev/) · [Kubernetes contributor guide](https://www.kubernetes.dev/)
