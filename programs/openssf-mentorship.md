# OpenSSF Mentorship

**What it is:** Open Source Security Foundation mentorships for **supply chain, tooling, and security** work on critical OSS.

**Who can apply:** Depends on project — often runs via **LFX Mentorship** terms.

**Stipend:** Paid in active LFX/OpenSSF cohorts.

**Official:** [openssf.org/get-involved/mentorship](https://openssf.org/get-involved/mentorship/)
