# Linux Kernel Mentorship Program (LKMP)

**What it is:** Structured mentorship from the Linux Foundation to help people contribute to the **Linux kernel** (often alongside Outreachy kernel projects in some rounds).

**Who can apply:** Developers ready for kernel workflow (C, mailing lists, patience with review cycles). Not the gentlest first OSS program.

**Stipend:** Varies by round — some cohorts are community/volunteer-focused; Outreachy kernel internships are **paid** separately.

**Typical application window:** Often **July–August** (check current year).

**Official:** [Linux Foundation LKMP wiki](https://wiki.linuxfoundation.org/lkmp) · Kernel newbies: [kernel.org](https://kernel.org/)

**Tip:** Start with [kernel newbies](https://kernelnewbies.org/) and small doc/driver fixes before applying.
