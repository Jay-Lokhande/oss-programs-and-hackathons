# LF Decentralized Trust Mentorship (Hyperledger / blockchain)

**What it is:** Linux Foundation **LFX** mentorship track for **Hyperledger** and decentralized-trust projects (blockchain, identity, etc.).

**Who can apply:** Same as LFX — apply to specific mentorship projects each term.

**Stipend:** Often **~$3,000–$6,600** (LFX table).

**Official:** [LFX Mentorship](https://mentorship.lfx.linuxfoundation.org/) · Filter for Hyperledger / LF Decentralized Trust
