# Free Software Foundation (FSF) Internship

**What it is:** Internships supporting **free software advocacy, GNU projects, and FSF operations** (remote, mission-driven).

**Who can apply:** Read current listing — often activists and developers comfortable with free software philosophy.

**Stipend:** Paid internships when positions are open.

**Official:** [fsf.org/volunteer/internships](https://www.fsf.org/volunteer/internships)
