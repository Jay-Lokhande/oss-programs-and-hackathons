# OSPP (Open Source Promotion Plan)

**What it is:** Chinese open-source promotion plan for **students**, pairing them with projects over a summer coding period. Stipends for accepted students.

**Who can apply:** Primarily students in the OSPP ecosystem — read official eligibility (often university students in China).

**Stipend:** Task difficulty tiers (often **¥4,000–¥12,000** range — verify current table).

**Official:** [summer-ospp.ac.cn](https://summer-ospp.ac.cn/) (verify URL each year)
