# Amazon Build for the World / AWS student programs

**What it is:** Amazon Science and AWS **student build challenges** (branding changes — search current year on official Amazon Science site).

**Who can apply:** Students per each challenge’s rules.

**Rewards:** Prizes, sometimes internship pipelines — not the same as GSoC.

**Official:** [amazon.science](https://www.amazon.science/) · [AWS student programs](https://aws.amazon.com/education/awseducate/)

**Hackathons:** See [hackathons/company-techathons.md](../hackathons/company-techathons.md).
