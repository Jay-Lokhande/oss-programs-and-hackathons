# Djangonaut Space

**What it is:** Free **8-week** group mentoring to contribute to **Django** and related projects (Navigators + Captains per team).

**Who can apply:** Open via application each session — global; no stipend.

**Official:** [djangonaut.space](https://djangonaut.space/) · [Program docs](https://github.com/djangonaut-space/program)

**Tip:** Strong bridge before GSoC on Django/Python web orgs.
