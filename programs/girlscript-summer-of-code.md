# GirlScript Summer of Code (GSSoC)

**What it is:** Large beginner-friendly open-source program — certificates, swag, and prizes (not a GSoC-scale cash stipend).

**Who can apply:** Beginners worldwide; popular entry point in India.

**Typical applications:** Often **March** (e.g. 2026 opened March 24 — verify next year).

**Official:** [gssoc.girlscript.tech](https://gssoc.girlscript.tech/)

**Tip:** Pair GSSoC with a paid program (GSoC, Outreachy, SoB) as you gain experience.
