# Code for GovTech (C4GT)

**What it is:** India-focused initiative connecting contributors with **government technology** open-source projects, often with paid fellowships/internships in active cycles.

**Stipend:** Paid fellowships (often cited around **₹1,00,000** per cycle — confirm on official site).

**Official:** [codeforgovtech.in](https://www.codeforgovtech.in/)

**Tip:** Strong if you want civic tech impact and can work with real-world deployment constraints.
