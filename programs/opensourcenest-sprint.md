# OpenSourceNest (OSN) Sprint

**What it is:** **4-week** mentored contribution sprint — contributors pick tagged issues; OSN mentors review before maintainers.

**Who can apply:** Open; beginner-friendly; fixed sprint dates (e.g. autumn sprints — check site).

**Stipend:** Certificates / badges — not a cash stipend.

**Official:** [opensourcenest.org](https://opensourcenest.org/)
