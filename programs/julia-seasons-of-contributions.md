# Julia Seasons of Contributions (JSoC)

**What it is:** Julia language ecosystem contributions — often aligned with **GSoC** / **Season of Docs** when Julia orgs participate.

**Who can apply:** Per Julia/GSoC project calls.

**Stipend:** Via GSoC/SoD when applicable.

**Official:** [julialang.org](https://julialang.org/) · Watch [Julia GSoC blog posts](https://julialang.org/blog/)
