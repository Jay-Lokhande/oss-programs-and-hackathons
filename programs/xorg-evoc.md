# X.Org Endless Vacation of Code (EVoC)

**What it is:** X.Org Foundation program funding **X11/Wayland/graphics stack** work with mentor pairing (similar spirit to GSoC, run by X.Org).

**Who can apply:** Developers with relevant C/graphics systems interest — read current EVoC criteria.

**Stipend:** Paid project funding when rounds are open.

**Official:** [XorgEVoC wiki](https://www.x.org/wiki/XorgEVoC/)
